# b2-a5

RentNest frontend for browsing rentals, sending requests, and managing properties by role.

## Features

- Public homepage, property search, filters, and details
- Tenant rental requests, payments, and profile
- Landlord property CRUD and incoming request handling
- Admin users, properties, requests, and categories

## Getting Started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and set the backend and JWT values.

Open [http://localhost:3000](http://localhost:3000).
